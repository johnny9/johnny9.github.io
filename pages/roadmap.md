# Roadmap

The long-term goal for the application is to become a full-featured bitcoin wallet with broad support across operating systems and devices, and to work well for both casual use and specialized use cases.

The current unsigned preview focuses on documenting and testing the app experience that is already treated as the current feature set: first use, block status, wallet management, activity, receiving, sending, settings, addresses, contacts, and console screens.
